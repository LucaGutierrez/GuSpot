# Emails de cuenta (plantillas de Supabase Auth)

Se cargan a mano en Supabase → Authentication → Emails → Templates (no se publican solas).
Salen por Resend desde `no-reply@guspotapp.com` (ver AGENTS.md).

| Plantilla en Supabase | Asunto | Archivo |
|---|---|---|
| Confirm sign up | Confirmá tu cuenta de GuSpot | `confirmar-cuenta.html` |
| Reset password | Creá una contraseña nueva en GuSpot | `recuperar-contrasena.html` |
| Change email address | Confirmá tu nuevo email en GuSpot | `cambio-de-email.html` |
| Reauthentication | Tu código de seguridad de GuSpot | `codigo-de-seguridad.html` |
